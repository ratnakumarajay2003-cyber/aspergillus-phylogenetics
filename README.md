# Comparative Phylogenetic Analysis of *Aspergillus* Species Using ITS DNA Sequences

## Project Overview

This project investigates the genetic relationships among different *Aspergillus* species using Internal Transcribed Spacer (ITS) ribosomal DNA sequences.

Publicly available nucleotide sequences will be retrieved from the NCBI database and analysed using bioinformatics tools to investigate sequence similarity, genetic variation and evolutionary relationships.

**Project Status:** In Progress

## Research Objectives

- Retrieve ITS DNA sequences of selected *Aspergillus* species from NCBI.
- Perform sequence similarity searches using NCBI BLAST.
- Conduct multiple sequence alignment using ClustalW.
- Construct a Maximum Likelihood phylogenetic tree.
- Visualise evolutionary relationships using FigTree.
- Perform additional sequence analysis using Python and Biopython.
